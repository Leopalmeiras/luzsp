# Configuração de provedores

O modo padrão é `COMPANY_DATA_PROVIDER=mock`. Para fonte licenciada, configure URL e chave somente no servidor, valide licença/termos e registre fonte/data. Google Places só pode ser ligado com credenciais oficiais e atribuição adequada; caso contrário a UI deve exibir “não consultado”. Validação externa de telefone não pode afirmar atividade ou WhatsApp sem fonte autorizada.
